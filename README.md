# Aditi's Dynamic Portfolio ⚡

A visually engaging, high-energy, and interactive portfolio website embodying the dynamic theme of the anime character Zenitsu Agatsuma. Built with modern web technologies, it features 3D elements, smooth scrolling, and vibrant animations to showcase projects, skills, and certifications.

## Features ✨

- **Zenitsu Theme:** Electric yellow, orange, and cream color palette with a dynamic layout.
- **Interactive 3D Elements:** Engaging 3D canvas rendering using Three.js.
- **High-Performance Animations:** Powered by GSAP for seamless entrance, scroll-triggered, and hover effects.
- **Smooth Scrolling:** Integrated with Lenis for a fluid navigation experience.
- **Showcase Sections:** Beautifully structured sections for an About page, Projects gallery, and Certifications.
- **Fully Responsive:** Optimized for both desktop and mobile devices.

## Technologies Used 💻

- **Bundler:** Vite
- **Languages:** TypeScript, HTML, CSS
- **Libraries/Dependencies:**
  - [Three.js](https://threejs.org/) (3D Graphics)
  - [GSAP](https://gsap.com/) (Animations)
  - [Lenis](https://github.com/darkroomengineering/lenis) (Smooth Scroll)

## Setup & How to Run Instructions 🚀

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js installed on your machine.
- [Download Node.js](https://nodejs.org/)

### Installation

1. **Open your terminal** in the project directory (`Aditi 1`).

2. **Install the dependencies:**
   ```bash
   npm install
   ```

### Running the Application Locally

1. **Start the development server:**
   ```bash
   npm run dev
   ```

2. **Open your browser** and visit the local URL provided in the terminal (usually `http://localhost:5173`).

### Building for Production

If you want to build the project for deployment:

1. **Run the production build command:**
   ```bash
   npm run build
   ```
   This will compile your TypeScript files and generate a `dist` folder containing the optimized static assets ready to be served.

2. **(Optional) Preview the production build locally:**
   ```bash
   npm run preview
   ```
